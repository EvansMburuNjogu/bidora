## 1. Objective
Persist exact external-source versions and concurrency-safe bid/requirement records.
## 2. Business Context
A compliance matrix must retain the requirement wording and source the team actually verified.
## 3. Scope
Opportunities, immutable verified versions, bid workspaces/decisions, requirements/assignments and document-evidence links. Response-evidence FK extension joins DB-006.
## 4. Out of Scope
AI-invented facts, title-only dedup, automatic generic status transitions.
## 5. Technical Requirements
UTC/zone/original wording; explicit unknown dates; local source-version FKs; approved active-workspace uniqueness with variant rules; expected versions; bid/status/owner indexes; no cascade deletion of evidence.
## 6. Proposed Implementation Approach
Implement reviewed migrations/queries; test unknown versus verified fields; parameterize filters/cursors; add same-bid linkage constraints and version-conditional updates.
## 7. Dependencies
[Common](BID-DB-003.md), [document schema](BID-DB-005.md), [contracts](../backend_contracts/BID-API-003.md).
## 8. Acceptance Criteria
- Given duplicate authoritative workspace without allowed variant, then uniqueness rejects it.
- Given stale requirement version, then update affects no row and yields conflict upstream.
- Given referenced source version, then deletion cannot destroy approved lineage.
## 9. Testing Requirements
FK/unique/status, null/zone, cursor stability, concurrent edits and query plans with representative matrix size.
## 10. Definition of Done
Verified migrations and typed owner queries with version/constraint evidence.

### Executable unverified-capture slice — 2026-10-18

Implemented a bounded Tenderpreneur migration for opportunity roots and immutable **UNVERIFIED** source versions, plus typed parameterized capture/idempotency/audit/outbox queries generated by sqlc v1.31.1 for pgx/v5. It preserves unknown dates and source wording/zone, checks request hashes and binds current source to the owning opportunity with a composite FK. [Design and verification evidence](../../../backend/docs/database-foundation.md).

This does not implement verified transitions, workspace/decision/requirement persistence, duplicate/variant policy or document tables. `source_document_version_id` remains a logical UUID pending BID-DB-005 FK/owner checks; no route may accept it yet. Goose validation, sqlc generation/drift and active Go checks passed, but no real PostgreSQL migration/constraint/transaction/isolation test ran. Parent remains Blocked.
