**Action flow rule:** show an action only when the current user has the exact capability, the operation is mounted and the record is eligible; a permission label alone does not grant access. Click opens a short form or consequence-specific confirmation; submit validates inputs, retains them on failure and displays a safe inline error; successful reads navigate to detail and mutations refresh server truth. A request awaiting approval shows its request status with a link to review for an authorized checker. A stale session or context returns to session resolution, not a guessed organisation. Unimplemented actions are absent with a clear unavailable explanation on the destination route, not disabled controls suggesting functionality.
